# PUPU

PUPU is a conversation companion for English learners.

The project combines authored educational content with a deterministic content factory that compiles approved conversation cards into runtime JSON.

## Current Status

- Content Factory architecture implemented
- Deterministic compiler
- Modular content packs
- Character animation system in development

This repository contains the source code and authoring documents for the PUPU project.
