# PUPU Project Rules

## What PUPU is

PUPU is an educational conversation companion for English learners.

It is built around a deterministic content pipeline.

AI may assist the author but must never replace author judgement.

## Core Principles

- Never invent educational content.
- Never simplify the architecture.
- Never replace deterministic systems with probabilistic ones.
- Never skip Factory stages.
- Follow all architecture documents exactly.
- If documentation conflicts, ask rather than guess.
- Preserve backwards compatibility whenever possible.
- Do not delete files unless asked.
- Do not rewrite large parts of the project without permission.

## Development Rules

Before making changes:

1. Read the relevant documentation.
2. Understand the existing architecture.
3. Explain your plan.
4. Make the smallest correct change.
5. Run tests.
6. Fix any failures.
7. Report exactly what changed.

If uncertain, ask.
